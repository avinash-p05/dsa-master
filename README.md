# DSA Master

A concept-first roadmap of 180 curated LeetCode problems for mid-level interviews. Each topic explains the pattern first, then lists its problems. Click a problem to solve it on LeetCode, then tick it off. Progress, notes and the 2/7/14-day review schedule are saved in your browser.

It's a static site (HTML, CSS and JS) with no build step. To add or change problems, edit `js/data.js`.

Run it locally:

```bash
python -m http.server 5173
```
